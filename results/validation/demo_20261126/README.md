# 演示视频运行验证

本目录记录公开仓库补充视频用例后的运行验证。测试台从仓库根目录启动，
使用 `demo/test_cases/cases.json` 自动发现 5 个小型 UCF101 视频和上游演示视频。

- 用例数：6
- 路线数：2
- 重复次数：3
- 推理次数：6 × 2 × 3 = 36
- 有明确 Kinetics 参考标签的 UCF101 用例：4
- 已知标签 Top-5：两条路线均为 4/4
- 两模型同时驻留时的进程峰值：437 MiB

“UCF101 开合跳”在 Kinetics-400 中没有同名类别，不参与准确率统计。
这些结果仅验证系统链路，不用于论文正式 UCF101 精度。
