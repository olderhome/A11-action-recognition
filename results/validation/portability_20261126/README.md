# 跨机器可运行性验证

- 验证日期：2026-11-26
- 验证基线：`8601f80`（修正安装核验与文档路径后）
- 系统：Windows 10 22H2
- GPU：NVIDIA GeForce GTX 1050 Ti 4 GB
- Python：3.11.9
- PyTorch：2.0.1+cu118
- MMAction2：1.2.0

## 验证方法

通过 `git archive HEAD` 导出仅包含 Git 跟踪文件的干净工程，并在独立目录中
运行。由于运行环境和演示权重按设计不进入 Git，验证时将已安装的 `runtime/`
与 `checkpoints/` 临时链接到干净工程，以模拟新电脑执行 `setup.ps1` 后的状态。

## 验证结果

- Git 归档中的 5 个演示视频和 Kinetics 标签文件齐全；
- `a11code.check_environment` 通过，全部依赖可导入；
- 5 项单元测试通过；
- `run_demo.ps1` 成功生成 `outputs/demo_tsn.mp4`；
- `run_comparison_app.ps1` 成功启动，并自动发现 6 个测试用例；
- 6 个用例 × 2 条路线 × 3 次重复的 36 次视频级推理全部完成；
- 4 个具有明确 Kinetics-400 对应标签的 UCF101 用例，两条路线均为 Top-5
  命中，Top-1 均为 4/4；
- 两模型同时驻留时，CUDA allocated 约 346.6 MiB、峰值约 436.9 MiB。

## 仓库内容控制

- 跟踪文件：1,205 个，未压缩约 44.0 MB；
- Git 归档压缩包约 23.8 MB；
- 演示视频及清单共 7 个文件，约 0.92 MB；
- 虚拟环境、模型权重、UCF101 完整训练数据、特征缓存和大体积结果不进入
  Git；权重由安装脚本按需下载。

## 判定

工程具备换机运行所需的源码、配置、标签、测试视频、依赖清单、安装脚本和启动
脚本。新 Windows 电脑需要安装 Python 3.10/3.11，首次联网执行
`setup.ps1`，之后无需手工配置路径即可启动演示。完整 UCF101 训练仍需按
`README.md` 单独准备数据和运行环境。
